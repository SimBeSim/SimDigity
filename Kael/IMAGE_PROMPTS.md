# Kael Image Prompts

This file contains copy/paste prompts (English + Dutch) and variants to generate the Kael headshots with an image model (Jinni or similar).

## Final Prompt (English, copy/paste)
Photorealistic cinematic headshot of a unique, human-realistic androgynous person in their mid-30s; include subtle asymmetry (e.g., slightly different eyebrow arches), refined angular facial features, almond-shaped eyes, short dark modern undercut, calm and curious gaze. Skin: natural light-olive to beige tone; minimal makeup; wardrobe: modern dark jacket visible at shoulders. Composition: 3/4 frontal, soft directional key light with gentle rim, shallow depth of field (85mm look). Jewelry: slim 14k yellow-gold name necklace on the collarbone clearly reading "Kael" in simple modern lettering; include a small discreet engraved SimDigity microtag on the clasp. Ultra-high detail (skin pores, hair strands). Output: 1024x1024 PNG with alpha. Provide variants: neutral, warm (half-smile), stern (focused), curious (raised eyebrow). Explicitly avoid resemblance to any real living person or celebrity, no watermarks, no text artifacts. If layered export (PSD) is supported, include separate layers for hair, face, and necklace.

Negative prompt: cartoon, painting, lowres, watermark, logo, celebrity likeness, text artifacts, extra limbs, overexposed, heavy makeup, stylized anime, sunglasses, hats, tattoos, blurred

### Expressive variants (append to main prompt)
- neutral: "expression: neutral, composed, slightly inquisitive"
- warm: "expression: gentle half-smile, approachable and warm"
- stern: "expression: focused, serious, slight furrow — thoughtful critique"
- curious: "expression: raised eyebrow, curious and engaged"

### Technical settings (recommended)
- Size: 1024×1024 PNG with alpha
- Guidance / CFG: 7–9
- Steps: 40–80
- Lens: 85mm, f/1.8 (include in prompt)
- Seed: record exact seed(s) for reproducibility
- Outputs: request separate layers (hair/face/necklace) if supported

### Consistency tips
- Use identical camera/lens/framing across family members for compositing
- Choose one metal finish (yellow gold) and keep it consistent
- Generate 3–5 seeds per expression, pick one canonical image and archive seed+prompt
- Request ±10° head rotations for simple face-rigging
